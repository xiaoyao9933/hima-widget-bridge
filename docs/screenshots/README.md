# 界面截图

这些文件取自智行快捷 0.6.0 的实机 UI 检查；0.6.1 保留所展示的首页、设置和标签页布局，主要修复标签写入后的验证流程。

- `home.png`：首页，数字钥匙状态、车锁／后备箱卡片、两个标签入口。
- `settings.png`：设置页上半部分，快捷项开关、固定到桌面、标签管理与连接权限。车辆小组件绑定入口位于下方，需要滚动。
- `trunk-tag.png`：后备箱标签管理页，未录入状态。车锁标签使用相同布局，标题和用途对应车锁。

截图通过 Android 应用内容视图直接渲染生成，不包含系统状态栏、通知、原版车辆小组件、车牌、VIN 或账号信息。连接状态和开关只用于界面示例，不代表首次安装后的默认状态。
